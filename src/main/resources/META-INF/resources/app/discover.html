How Federation Works
  1. You enter @alice@mastodon.social in the search box
  2. Open Pace sends a WebFinger query to resolve the address
  3. WebFinger returns the actor profile URL on the remote server
  4. The profile is fetched directly from the remote instance
  5. Click Follow to send a Follow activity to their inbox
  6. Alice's activities now appear in your feed!
